# Taters Range

Small 3D shooting range to get the character, guns, and FPS controls right before the open world.

Quaternius UAL mannequin + outfits + weapons. Play in the browser.

## Play on your machine

Needs Node 20+.

```bash
git clone https://github.com/johr77/Tatersopenworld.git
cd Tatersopenworld
npm install
npm run dev
npx vite dev --host 127.0.0.1 --port 8080
```

Open the URL it prints (usually `http://localhost:8080`).

## Controls

| Action | Keyboard | Xbox |
| --- | --- | --- |
| Move | WASD | Left stick |
| Look | Mouse | Right stick |
| Jump | Space | A |
| Crouch | Ctrl | B |
| Sprint | Shift | LS click |
| Fire | Left mouse | RT |
| Aim | Right mouse | LT |
| Reload | R | X |
| Swap gun | 1 / 2 / 3, mouse wheel | D-pad |
| First / third person | V | Y |
| Options | Esc | Menu |

Make a player, pick a look (Mannequin is the raw UAL body — use it to compare walks against the clothes).

## Assets

CC0. Character and outfits by Quaternius. Gunshots recorded by Vince Sevedge / Tabasco (OpenGameArt).
